# Shell, loops, conditions and parsing

This repository contains Shell scripting tasks focused on loops, conditions, and parsing for the ALU Software Engineering program.

## Description
Learning how to use `for`, `while`, `until` loops, `if/elif/else` conditions, `case` statements, and parsing with `cut`, `awk`, and file tests in Bash.

## Requirements
- Ubuntu 20.04 LTS
- Bash
- Shellcheck (version 0.7.0)
- All scripts start with `#!/usr/bin/env bash`
- Second line is a comment explaining the script
- All files are executable
